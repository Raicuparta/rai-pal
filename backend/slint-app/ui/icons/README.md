# Icons

- `providers/*` and `engines/*` are brand SVGs from
  [Simple Icons](https://simpleicons.org) (CC0), except `providers/xbox.svg`,
  which is from [Tabler Icons](https://tabler.io/icons) (MIT) because Simple
  Icons no longer includes Xbox.
- Generic UI icons come from [Lucide](https://lucide.dev) via the
  `lucide-slint` package.
